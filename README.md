# feedish

*Feedish* is a project where I create, tweak or combine various news feeds (RSS etc.) for convenience or special purposes. Either to be served for my newsreader — or as a "preburner API" for other (future planned) projects/ideas.

Feedish uses [*Feedsmith* by *Maciej Lamberski*](https://github.com/macieklamberski/feedsmith) ([MIT](https://github.com/macieklamberski/feedsmith/blob/main/LICENSE) licensed) and [*domparser* by *thednp*](https://github.com/thednp/domparser) ([MIT](https://github.com/thednp/domparser/blob/master/LICENSE) licensed).

This is a *Deno Deploy project* deployed at https://feedish.stignygaard.deno.net/.
While source-code of _Feedish_ has home in a _public_ repository, it is still a "personalized" project. If you fork/copy it, please remember to remove any personal references, for example in the HTML pages.
